05 / Replaceable

可替換位置

  • App 名稱／頁首文案：而家用「今日要做」，wireframe 上標 ⟨名稱⟩。三個方案刻意用同一名稱，方便比較排版而非比較文案。
  • 示範待辦資料：交課程計劃書、2026-11-20、tags「工作／急」取自 spec §5 範例；其餘幾條係展示用，標 ⟨示範資料⟩，可整套換成真實資料。
  • 字體：本頁為零依賴離線檔，用 system font stack 模擬三種字感；上線建議 A = Baloo 2、B = Nunito Sans / Varela Round、C = Libre Bodoni + Public Sans。若改走 CDN，要按 spec §6.1 做釘版 ＋ SRI ＋ CSP，SRI hash 執行時實計，唔准寫死。
  • 色值與圓角：可換成品牌色，但換完要重驗文字對比 ≥4.5:1（尤其 B 嘅漸層 CTA 同 C 嘅螢光色塊）。
  • 進度摘要計算方式：而家寫「1 / 4 完成」，spec 未規定文案，屬 UI 自由位。
06 / How to choose

點樣揀

先喺上面「並排對照」用同一組資料睇三款首頁嘅第一眼感覺，再逐個撳入去睇兩屏 wireframe 嘅區塊標註同操作流程。揀好之後撳「揀呢個方案」，本頁會記低偏好（存喺本機瀏覽器）；之后可以直接報方案代號俾我，我會按 docs/spec.md 嘅 Vanilla JS ＋ 零 build 約束落實做 design tokens 同 public/ 頁面。
